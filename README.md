UrbanSense-AI is a machine learning-powered web application designed to analyze urban environmental conditions, including temperature, Air Quality Index (AQI), and noise pollution. The platform provides interactive visualizations, environmental insights, and AI-based predictions through an intuitive Streamlit dashboard.

🔗 **Live Demo:** [Launch UrbanSense-AI](https://urbansense-ai-kl26qjxurxibnhfmqqd6zs.streamlit.app/)

---

## 📌 Project Overview

Urbanization has increased environmental challenges such as air pollution, rising temperatures, and excessive noise. UrbanSense-AI aims to support environmental analysis through data analytics and machine learning.

The application allows users to explore environmental datasets, visualize city-wise patterns, and generate predictions using machine learning models.

## ✨ Key Features

- 🌡️ **Temperature Analysis** — Analyze temperature patterns across cities.
- 🌫️ **Air Quality Analysis** — Explore and visualize AQI levels.
- 🔊 **Noise Pollution Analysis** — Examine urban noise pollution patterns.
- 📊 **Interactive Dashboard** — View environmental statistics and visualizations.
- 🤖 **AI-Based Prediction** — Generate environmental predictions using machine learning.
- 🗂️ **Dataset Exploration** — Browse and analyze environmental datasets.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/SenArush/UrbanSense-AI.git
cd UrbanSense-AI
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate the environment:

**Windows**
```bash
venv\Scripts\activate
```

**Linux / macOS**
```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run src/app.py
```

The application will open in your browser at:

```text
http://localhost:8501
```
